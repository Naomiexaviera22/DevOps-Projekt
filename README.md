# DevOps-Projekt — Notes App

A simple Notes REST API built with Spring Boot, containerized with Docker.

## Run locally

```bash
docker compose up --build
```

Then visit: `http://localhost:8080/notes`

## Roles

- Versionierung & Ticketverwaltung
- Softwareentwicklung
- Infrastruktur & Umgebung (Docker)
- Build & Deployment (CI/CD)
- Qualitätssicherung
